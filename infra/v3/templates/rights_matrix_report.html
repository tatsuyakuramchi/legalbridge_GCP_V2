  1. 許諾は、作品と派生作品（言語版など）の OUT の利用許諾の条件（有効・予定）です。{{#unless includeEnded}}基準日より前に終わった許諾は載せていません。{{/unless}}
  2. 地域・言語を挙げていない条件は、その次元が無制限（全世界・全言語）として全部のマスを覆います。「その他の地域」「その他の言語」は表に出ていない国・言語のまとめで、全世界・全言語の許諾だけが覆います。
  3. 「ぶつかり」は、独占の許諾が期間の重なるほかの取引先の許諾と同じマスにあること。「範囲外」は、作者から取った範囲（作者の条件の地域・言語）の外で許諾していること。「空き」は、取った範囲の内でまだ誰にも許諾していないマスです。
    4. {{#unless isWork}}
  4. 地域を選ばないときは、その言語の全地域を畳んで、いちばん気にすべき状態（ぶつかり → 範囲外 → 独占 → 非独占 → 空き）で出します。派生作品の許諾は元の作品の行にまとめています。
    5. {{/unless}}
