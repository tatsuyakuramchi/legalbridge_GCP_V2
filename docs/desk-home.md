# ホーム：今日やること と 作業台

対象: `apps/legalbridge-v3`（`src/client/DeskHome.tsx`・`src/server/desk/desk-service.ts`）

UI 再構築の手順 1。ホームを「今日やること」（受信箱）と、畳んだ「作業台」（ツリー + 詳細）に置き換える。
旧ホームの盤面は消さず、ホームの下の「以前のホーム（盤面）を見る」を押したときだけ出す。
ほかの画面と URL は変えない。

## 1. 何が出るか

| 場所 | 中身 | 読むタイミング |
|---|---|---|
| 今日やること | 受付箱（新規・更新あり）、自分のデイリータスク、14 日以内の期限（案件・契約・支払・予定） | ホームを開いたとき |
| 作業台のツリー | 根を「取引先 / 案件 / 作品」で切り替える一段目。取引先の下は基本契約・単体契約と「契約に紐づかない条件」 | 作業台を開いたとき。取引先の下は枝を開いたとき |
| 作業台の中身 | 案件・取引先・契約は工程表（`WorkLedger`）。作品は回と文書（`WorkRounds`）と工程表 | ツリーで選んだとき |

- 今日やることは期限切れ → 今日 → 今週 → それ以降 → 期日なしの順。5 件を出し、残りは「すべて見る」。
- 行を押すと作業台が開き、その相手（案件・取引先）を選ぶ。右のボタンは元の画面（受付箱・デイリータスク・案件・契約・支払・取引管理）を開く。
- 作業台の開閉と根は、この端末に覚えておく（`localStorage`。覚えられなくても動く）。
- 文書を作るのは案件を選んだときだけ。取引先・作品の切り口は案件をまたぐので、行から案件を開いて作る。

## 2. 軽さの決まり

- ホームを開いたときの問い合わせは `/desk/today` の 1 本だけ。中では受付箱 2 本・デイリータスク・期限を **並べずに 1 本ずつ** 読み、結果を **1 分覚える**（担当ごと。同時に来た要求は 1 回の計算に相乗り）。
- 旧ホームの `/home/stations`（10 本の集計）・`/summary`・`/drift/count`・`/deadlines` は、盤面を出したときしか呼ばない。
- ツリーの一段目は 100 件まで。検索語の無い一段目は 1 分覚える。取引先の下は開いたときだけ読む。
- 取引先の工程表（`/parties/:id/grid`）は新しい順に 500 行まで。

## 3. API

| Method | Path | 中身 |
|---|---|---|
| GET | `/desk/today?assignee=<staffId>` | 今日やること。`assignee` はデイリータスクの担当（無ければ全員） |
| GET | `/desk/tree?root=party\|matter\|work&q=` | ツリーの一段目 |
| GET | `/desk/tree/party/:id` | 取引先の下（契約と、契約に紐づかない条件の本数）。補助文書の条件は親の契約に数える |
| GET | `/parties/:id/grid` | 取引先 1 社の工程表（案件をまたいで全部。列は案件の工程表と同じ） |

工程表の行（`GridRow`）に `agreementId` を足した。作業台で契約ごとに絞るのに使う。

## 4. 契約・文書（取引先の切り口）

取引先（またはその下の契約）を選ぶと、右の中身の上に「工程表（条件ごと）」「契約・文書」の切り替えが出る（この端末に覚える）。
「契約・文書」は取引先⇔基本契約の図（`PartyMapView`）をそのまま出し、作業台の中で次をする（`src/client/DeskContracts.tsx`）。

| やること | どこで |
|---|---|
| 基本契約・単体契約・NDA などを登録して番号を取る | 「＋ 契約を登録（番号を取る）」。まだ締結していなければ「まだ締結していない」で交渉中のまま番号だけ取る（締結日は後で「編集」） |
| 基本契約の下に個別契約を足す | 基本契約の行の「＋ 個別契約」（番号は親の番号＋枝番） |
| 契約書の PDF を登録してクラウドサインで送る | 登録した直後の「契約書を登録する」欄か、契約の行の「文書」。チェックを入れておくとそのまま署名者の入力へ |
| 文書を探して契約に登録・送る／契約ごとに送る | 図の下（取引先⇔基本契約の画面と同じ） |

読むのはタブを開いたときの `/agreement-map/parties/:id` 1 本。工程表に切り替えたときは読まない。

工程表の「契約のみ」の段にも同じ入口を置いた。

- 案件か契約を選んでいるとき：「＋ 番号だけ取る」の横に「＋ 外で作った文書を登録（PDF）」。
- 番号だけ取った文書の「PDF を取り込む」：取り込んだら、その行の下にクラウドサインの宛先入力を開く（管理者・連携が止まっていないとき）。
- 取り込んだ文書で締結がまだの行：送付の欄に「クラウドサインで送る」。送ったら送付の欄に「CloudSign 下書き」（黄）・「CloudSign で送付」（済）と出る。
  手で締結を記録したものや外で送ったものは、今までどおり「— 外で送付」（止まりにはしない）。
